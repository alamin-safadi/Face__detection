# 🎯 Age Detection with Emotion Recognition

This is a **real-time computer vision application** that detects human faces from a webcam feed and analyzes each face to estimate **age** and identify the **dominant emotion**.  
The project is built using **Python, OpenCV, and DeepFace**.

---

## ✨ Features
- Real-time face detection using webcam
- Age estimation using deep learning
- Emotion recognition (happy, sad, neutral, etc.)
- Live display of face count, age, and emotion
- Lightweight and easy to run locally

---

## 🛠️ Technologies Used
- **Python**
- **OpenCV**
- **DeepFace** (TensorFlow / Keras based)
- **Haar Cascade Classifier**
